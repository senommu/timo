# Timo icon

Timo has one icon: the minimal mushroom in `Timo.svg`. The editable Icon Composer document is `AppIcon.icon`; its only layer uses the same vector. The mark has a subtle silver glass fill on a light background, with no shadows or extrusion.

Run `scripts/compile-app-icons.sh` to regenerate the native catalogue and compatibility icon. Old saved icon choices migrate to Timo.
